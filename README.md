# LimonCher

LimonCher 0.5.6-AndroidVer — Minecraft Java Edition focused Android launcher.

Package: `com.limone.limoncher`

Developer: Limone Production, RedzDev

GitHub Actions workflow: `.github/workflows/launcher-release.yml`

## Build

`./gradlew :LimonCher:assembleRelease -Darch=arm`

`./gradlew :LimonCher:assembleRelease -Darch=arm64`

`./gradlew :LimonCher:assembleRelease -Darch=x86`

`./gradlew :LimonCher:assembleRelease -Darch=x86_64`

`./gradlew :LimonCher:assembleRelease -Darch=all`
